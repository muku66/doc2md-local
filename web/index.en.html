Tools · On-device · no upload

PDF / Word / PPT / Excel to Markdown

Files are processed in your browser and are never uploaded. All dependencies are included; run a local server to use it offline. Supports .pdf, .docx, .pptx and .xlsx (Excel also exports full CSV files).

Or drag files here

Limits: scanned PDFs (pictures of pages) cannot be read because there is no OCR; the old .doc / .ppt / .xls formats are not supported; PDF tables and complex layouts are only roughly recovered, so please check the result. Images are not exported.
Open-source libraries: PDF.js(Apache-2.0), JSZip(MIT). License texts: LICENSES.txt.

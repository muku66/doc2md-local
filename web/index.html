PDF / Word / PPT / Excel 转 Markdown

文件只在你的浏览器里处理，不会上传。所有依赖均随仓库提供；本地启动后可离线转换。支持 .pdf、.docx、.pptx、.xlsx（Excel 同时导出完整 CSV）。

也可以把文件拖到这里

局限：不能识别扫描版 PDF（没有文字识别），不支持旧格式 .doc / .ppt / .xls；PDF 的表格和复杂排版只能做基本还原，转换后请检查。图片不会导出。
使用的开源库：PDF.js（Apache-2.0）、JSZip（MIT）。许可证文本见 LICENSES.txt。
